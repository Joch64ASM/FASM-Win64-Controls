Native Windows programming, from the metal up.

Learn native Windows GUI programming using pure FASM x64 and the Win32 API. The examples don't only show which code to write — they explain why Windows behaves the way it does.

Philosophy

Understand the API, not just the example.

Every example is intended to compile, run and teach. The project stays close to Windows itself rather than hiding the operating system behind a framework.

01 / NATIVE

No GUI framework

Native Win32 windows, messages, controls, GDI and Common Controls directly from FASM x64.

02 / EXPLAINED

Why Windows does it

Message routing, ownership, notification structures, painting and ABI rules are explained instead of treated as magic.

03 / MODERN

Win64 first

Unicode APIs, the Windows x64 calling convention, DPI awareness and modern native control techniques.
