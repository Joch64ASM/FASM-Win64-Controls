Graphics Track · GDI

Draw the complete Win64 interface yourself with GDI.

This is not a course about accepting the default look of standard Windows controls. The goal is to take responsibility for the pixels the user sees: the dark window surface, title area, borders, text, buttons, selection rows and the visual treatment of the controls we add.

Native behavior stays underneath. USER32 still gives us HWNDs, messages, keyboard input, mouse capture, hit-testing, focus and control notifications where they are useful. GDI is where we take over the visible interface. A native control can still exist as a real child window while its appearance is completely drawn by our own code.
